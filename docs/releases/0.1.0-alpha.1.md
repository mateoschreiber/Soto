# Soto 0.1.0-alpha.1

Primera distribución pública de la interfaz de demostración, escrita en Rust y preparada para Docker Linux amd64 (Intel/AMD). Licencia MIT para el código propio.

- Interfaz editorial clara con verde mate, iconos grandes y centrados.
- Local y Torrents separados, búsqueda, filtros, fichas y colecciones de ejemplo persistentes en el navegador.
- Diseño adaptable y vista TV web con navegación por teclado.
- Imagen precompilada, usuario sin privilegios, raíz de solo lectura, healthcheck y recursos configurables.
- Gzip preparado en el build y caché por huella de contenido, sin compresión por petición.
- Instalación mediante Compose, Portainer o imagen portátil adjunta.

**Esta versión no reproduce películas, escanea archivos, descarga torrents ni conecta Real-Debrid. No contiene autenticación ni APK Android TV. No se ha validado ARM.** Úsala en una red de confianza o detrás de controles de acceso propios.

Imagen: `ghcr.io/mateoschreiber/soto:0.1.0-alpha.1`. Para el archivo portátil, descarga el `.tar.gz`, `soto-compose.yaml` y `SHA256SUMS`, comprueba las sumas y carga la imagen con Docker. Instrucciones completas en [la guía de instalación](https://github.com/mateoschreiber/Soto/blob/v0.1.0-alpha.1/docs/installation.md).

No se redistribuyen portadas ni películas. Los recursos externos conservan sus derechos originales.
